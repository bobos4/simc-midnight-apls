# SimulationCraft Midnight APL Mirror

This repository is an automated, read-only mirror of the default Midnight
Action Priority Lists from SimulationCraft:

- Source repository: <https://github.com/simulationcraft/simc>
- Source branch: `midnight`
- Source directory: [`ActionPriorityLists/default`](https://github.com/simulationcraft/simc/tree/midnight/ActionPriorityLists/default)

The synchronization workflow runs every six hours and can also be started
manually. It creates a commit only when one or more `.simc` files change, so
the repository history stays focused on APL updates.
